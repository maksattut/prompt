Рекомендуемый запуск:
1. Ведущий открывает презентацию PPTX или PDF.
2. Участники открывают Workbook.html на ноутбуке или телефоне.
3. Ведущий держит отдельно Facilitator_Guide.pdf или TXT.
4. В конце участник сдает экзаменационный артефакт по рубрике.

Главная формула курса:
Задача -> Контекст -> Действие -> Ограничения -> Формат -> Проверка -> Решение человека

Важно:
Работайте только с безопасными и разрешенными данными. Существенные управленческие решения остаются за человеком.
